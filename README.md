## 更新 GitHub Pages

必要更新：

- `index.html`：12 天行程、待辦、速查與手機介面。

```bash

git commit -m "Update Fukushima itinerary to 2026-10-12"

```

`manifest.webmanifest`、原有四個圖示檔不需變更。兩份私人行程文件、原 ZIP、測試腳本、私人進度備份不需上傳。

## iPhone 更新後

1. 等 Pages 部署完成，以原網址連網重新整理。
2. 頁尾應顯示「行程更新 2026/10/12」。仍舊版時，關閉 Safari 分頁／主畫面 App，再開啟。
3. 看到「已備妥離線行程」後再離線使用；地圖與官網需連線。

Safari「分享 → 加入主畫面」可用 App 模式。保留原網址、瀏覽器及網站資料，才能沿用本機進度；不需清除網站資料。
